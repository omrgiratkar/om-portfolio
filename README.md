# Om Giratkar — 3D Portfolio (React + TypeScript + Vite)

Stack: React 18, TypeScript, Vite, Tailwind CSS v4, Three.js, Framer Motion.

    npm install
    npm run dev       # http://localhost:5173
    npm run build     # production build in dist/
    npm run preview

Edit content in `src/data.ts`. Replace `public/profile.jpg` and `public/Om_Giratkar_Resume.pdf` to update the photo and resume.
Deploy `dist/` to Netlify, Vercel, GitHub Pages, etc.
